# 花園トキネDS v1.2.3

OpenUtau向けの歌声データベースです。高音WORLD処理、ロングトーンの持続・終端調整、摩擦子音接続に加え、短い母音や連続同母音の接続を改善しました。

## 導入

OpenUtauの「ツール」→「音源をインストール」から `HanazonoTokineDS-v1.2.3.zip` を読み込んでください。歌手名は「花園トキネDS v1.2.3」です。Pythonや追加プラグインは不要です。

## 対応環境

macOS Apple Silicon / OpenUtau AU v0.1.572.1で実フレーズを合成して確認しました。Windows・Linux・他のDiffSingerエディターは未検証です。

音響モデルと同梱ボコーダーをセットで使用してください。この版は音響モデルからボコーダーへ2組のmelを渡すため、これに対応しないソフトでは動作しません。従来版より合成時間とメモリー使用量が増えます。

利用条件はTERMS.md、第三者素材の表記はTHIRD_PARTY.mdをご確認ください。
