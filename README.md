# 花園トキネDS

OpenUtauで使える日本語のDiffSinger歌声音源です。本人歌唱をもとにした配布版です。v1.1.0では発音の安定化を目的に音響モデル構成と合成設定を更新しました。

[最新版の配布ZIPはこちら](https://github.com/sotwat/hanazono-tokine-ds/releases/latest)

## 導入

1. GitHub ReleasesからZIPをダウンロードして展開します。
2. OpenUtauの「ツール」→「音源フォルダを開く」で開いたSingersフォルダへ、展開した「花園トキネDS」フォルダを入れます。同名の音源がある場合は先に別の場所へ退避してください。
3. OpenUtauを再起動し、歌手「花園トキネDS」を選びます。
4. フォネマイザを「DIFFS JA」、レンダラーを「DIFFSINGER」に設定します。

ボコーダーを同梱しているため、別途のボコーダー導入は不要です。OpenUtau AU v0.1.572.1で今回のモデルの通常域・高音域の歌唱を確認しています。配布構成では全8モデルの読み込み・設定参照・ZIP整合性を検査しました。配布ZIPを新規導入した環境での歌唱は未検証です。

## 歌わせ方と対応機能

歌詞はひらがなで入力します。小さい「っ」や「ん」も入力できます。まず音符の音程・長さと歌詞を整えてから再生してください。

音程カーブと音量カーブを使用できます。GENC、VELC、ENE、BREC、VOIC、TENCの専用制御モデルは含まれていません。推奨の比較設定は20 steps・depth 0.10（音源設定で深さの上限を0.10に制限）です。

## 音源について

25曲分の候補素材から品質を選別し、本人の実録音271区間とNIT SONG070 F001の249区間を使った2話者学習を利用しています。本人の学習区間が残った曲数は24曲です。花園トキネの声へ固定して書き出しています。PJSを追加した試作モデルは含みません。

18曲版の音素・音高などの条件を処理する部分と補助デコーダーを維持し、追加学習した拡散モデルを組み合わせています。音長・音程モデルは従来版と共通です。発音の安定化には合成深さの変更も寄与しており、追加学習だけによる改善を示すものではありません。

発音の不明瞭さや、音域・歌詞による声質のばらつきが残る場合があります。全ての音域・歌詞での音質改善を保証するものではありません。
