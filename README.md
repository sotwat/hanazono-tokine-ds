# 花園トキネDS

OpenUtauで使える日本語のDiffSinger歌声音源です。本人歌唱をもとにした配布版です。v1.1.1では発音の安定化を目的に音響モデル構成と合成設定を更新しました。

## ダウンロード

[最新版の配布ZIPはこちら](https://github.com/sotwat/hanazono-tokine-ds/releases/latest)

[v1.2.2](https://github.com/sotwat/hanazono-tokine-ds/releases/tag/v1.2.2)では持続音の音色の揺れを抑え、母音から摩擦子音への接続を調整しました。高音WORLD処理とロングトーンの持続改善も含みます。同梱モデル一式とbatch 2を渡せるソフトが必要です。対応環境・制限は同梱READMEをご確認ください。

## 導入

1. GitHub ReleasesからZIPをダウンロードして展開します。
2. OpenUtauの「ツール」→「音源フォルダを開く」で開いたSingersフォルダへ、展開した「花園トキネDS v1.2.2」フォルダを入れます。同名の音源がある場合は先に別の場所へ退避してください。
3. OpenUtauを再起動し、歌手「花園トキネDS v1.2.2」を選びます。
4. フォネマイザを「DIFFS JA」、レンダラーを「DIFFSINGER」に設定します。

ボコーダーを同梱しているため、別途のボコーダー導入は不要です。OpenUtau AU v0.1.572.1で今回のモデルの通常域・高音域の歌唱を確認しています。配布構成では全8モデルの読み込み・設定参照・ZIP整合性を検査しました。配布ZIPを新規導入した環境での歌唱は未検証です。

## 歌わせ方と対応機能

歌詞はひらがなで入力します。小さい「っ」や「ん」も入力できます。まず音符の音程・長さと歌詞を整えてから再生してください。

音程カーブと音量カーブを使用できます。GENC、VELC、ENE、BREC、VOIC、TENCの専用制御モデルは含まれていません。推奨の比較設定は20 steps・depth 0.10（音源設定で深さの上限を0.10に制限）です。

## 音源について

25曲分の候補素材から品質を選別し、本人の実録音271区間とNIT SONG070 F001の249区間を使った2話者学習を利用しています。本人の学習区間が残った曲数は24曲です。花園トキネの声へ固定して書き出しています。PJSを追加した試作モデルは含みません。

18曲版の音素・音高などの条件を処理する部分と補助デコーダーを維持し、追加学習した拡散モデルを組み合わせています。音長・音程モデルは従来版と共通です。発音の安定化には合成深さの変更も寄与しており、追加学習だけによる改善を示すものではありません。

発音の不明瞭さや、音域・歌詞による声質のばらつきが残る場合があります。全ての音域・歌詞での音質改善を保証するものではありません。

## v1.2.1の母音接続

長い母音同士の接続で、音量の落ち込みと立ち上がりを調整しました。両方の母音が約0.46秒以上の場合、境界の前後約90ミリ秒で音色を連続的に移します。音源内の共通処理で、音符や歌詞の位置は変更しません。制作者が試聴・承認したv1.2.1-rc.2と同じモデルです。

## 持続・高音処理

D5からF5にかけて高音WORLD処理を段階的に適用します。0.46秒以上の母音・一部持続子音は前半の声を使って持続させ、短い持続音では強い区間を自動選択します。つながる音とフレーズ末尾で終端処理を変えています。次の子音の先行で母音が短い場合は、譜面側の音素位置調整が必要です。

## 旧v1.1.1の音域別補正

F5はEQのみ、F#5以上はEQ・+3 dB・弱いサチュレーションを適用します。EQは基音付近+4 dB、第2倍音付近+2.5 dB、5 kHz高域棚−2.5 dB。サチュレーションはdrive 2・混合25%。E5以下は変更しません。ピーク保護により大振幅時の増幅量は抑えられます。判定は合成F0を使います。補正ONNXの実行を検証済みです。今回の配布ZIPによる新規環境での歌唱は未検証です。

## v1.2.2の持続と子音接続

持続区間の音色を安定させ、約0.46秒以上の母音からf・h・s・sh・zへ切り替わる際の急な変化を和らげました。音源に組み込んだ共通処理です。
