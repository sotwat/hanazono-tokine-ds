# 母音接続の試作

Python / PyYAMLで `python connect_a_vowels.py SOURCE.ustx TRIAL.ustx` を実行します。接している「あ」の2音目以降をOpenUtauの継続記号 `+` に変更します。音程・長さは維持します。再発音が必要な箇所には適しません。これは譜面側の比較試作で、モデル自体の改良ではありません。
